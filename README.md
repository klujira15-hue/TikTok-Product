# TikTok Product — Rujira

โปรแกรมค้นหาสินค้า TikTok Shop สำหรับนายหน้า พร้อมลิงก์สินค้า ดาว/รีวิว ดาวร้าน ค่าคอมต่อชิ้น และ Angel Score สำหรับเลือกสินค้าทำวิดีโอ

## โครงสร้างหลัก

| โฟลเดอร์ | หน้าที่ |
| --- | --- |
| [`app/`](app/) | โปรแกรมหลักและหน้าเว็บ รุ่น 1.4.0 |
| [`extension/`](extension/) | ส่วนขยาย Chrome เชื่อมข้อมูล TikTok Creator รุ่น 1.1.1 |

## เปิดโปรแกรม

ติดตั้ง [Node.js 24 ขึ้นไป](https://nodejs.org/) แล้วเปิด `app/Start.cmd` บน Windows หรือใช้คำสั่ง:

```sh
cd app
npm start
```

เปิด [http://127.0.0.1:4317](http://127.0.0.1:4317) โปรแกรมใช้โมดูลที่มากับ Node.js จึงไม่ต้องติดตั้ง dependencies เพิ่ม

## ติดตั้งส่วนขยาย

1. เปิด `chrome://extensions` และเปิด Developer mode
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension` ที่อยู่ข้าง `app`
3. เปิดโปรแกรมหลักและเข้าสู่ระบบบัญชี TikTok Creator ที่ใช้เป็นนายหน้า
4. เปิดหน้าโปรแกรมค้างไว้เพื่อให้ส่วนขยายตรวจค่าคอมเบื้องหลัง หากติดตั้งรุ่นเก่าอยู่แล้วให้กด Reload ส่วนขยายและรีเฟรชหน้าโปรแกรม

การค้นหาส่งคำค้นใหม่ไป TikTok โดยตรง ไม่ต้องเตรียมรายการสินค้าล่วงหน้า โปรแกรมค้นหน้าถัดไปและหมวดที่ TikTok ส่งลิงก์มา ขณะตรวจรายละเอียดและค่าคอมแยกกัน

ตารางและ CSV แสดงเฉพาะสินค้าตรงคำค้น มีดาวสินค้าและรีวิวมากกว่า 0 และยืนยันค่าคอมนายหน้าจาก TikTok Creator มากกว่า 0 รายการรอตรวจ ตรวจไม่ได้ ไม่ร่วม Affiliate หรือค่าคอม 0 จะไม่แสดงเป็นสินค้าที่พร้อมเลือก

ผลค้นหาเป็นข้อมูลที่แหล่งเว็บและบัญชีที่ใช้งานส่งมาในรอบนั้น ไม่รับรองว่าเข้าถึงสินค้าครบทั้งแพลตฟอร์ม Angel Score เป็นสูตรช่วยคัดเลือกของโปรแกรม ไม่ใช่คะแนนรับรองจาก TikTok

## ข้อมูลในเครื่อง

ฐานข้อมูลจะถูกสร้างเมื่อรันโปรแกรม ค่าเริ่มต้นอยู่ที่ `~/Documents/Codex/RujiraProductFinder/data` กำหนดโฟลเดอร์อื่นได้ด้วย `DATA_DIR` และกำหนดพอร์ตได้ด้วย `PORT` แต่ส่วนขยายรุ่นนี้เชื่อมพอร์ต `4317`

Repository นี้เก็บซอร์สโค้ด ไม่รวมฐานข้อมูลใช้งาน ผลค้นหา ไฟล์สำรอง ค่าจับคู่ Cookie หรือ Token ของบัญชี
