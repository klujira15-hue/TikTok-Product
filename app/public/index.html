รับข้อมูลที่หน้าเว็บเรียกใช้อยู่

ส่วนขยายจะอ่านเฉพาะคำตอบ JSON บน TikTok ที่คุณเปิดใช้งาน ไม่เก็บ Cookie, Authorization header หรือ Access Token

  1. เปิด chrome://extensions หรือ edge://extensions แล้วเปิดโหมดนักพัฒนา
  2. เลือก Load unpacked และเลือกโฟลเดอร์ extension ของโปรแกรมนี้
  3. เปิดส่วนขยาย ใส่ Server URL และรหัสจับคู่ด้านล่าง แล้วกดเปิดรับข้อมูล
  4. รีเฟรช TikTok Shop แล้วค้นหา เปิดสินค้า หรือเลื่อนดูผลลัพธ์ ข้อมูลที่อ่านได้จะทยอยเข้าผลค้นหา

รองรับ fetch / XHR ที่ส่ง JSON ในหน้าที่เปิดอยู่ หากเว็บส่งรูปแบบอื่น ข้อมูลอาจไม่ปรากฏ ใช้นำเข้า JSON/HAR เพื่อตรวจได้ ไม่ข้ามหน้า Security Check และไม่ดึงสินค้าทั้งแพลตฟอร์มในครั้งเดียว

ค่าคอมสำหรับนายหน้า

เปิด TikTok Creator LIVE Manager ↗ → Showcase Products → Add new products → วางลิงก์ทีละรายการ → Product URLs เพื่อดูค่าคอม ส่วนขยายจะรับข้อมูลจากคำตอบตรวจลิงก์นี้ ไม่ต้องเพิ่มสินค้าเข้าบัญชี

จำนวนเงินต่อชิ้นเป็นประมาณการจาก TikTok Creator ณ เวลาที่รับ ราคาฝั่ง Creator อาจต่างจากราคาหน้าร้าน รายได้จริงขึ้นกับราคาชำระ คูปอง ภาษี และเงื่อนไขของแต่ละคำสั่งซื้อ
