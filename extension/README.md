# ส่วนขยาย Rujira

Chrome Extension รุ่น 1.1.1 ใช้ร่วมกับโปรแกรมหลักใน [`../app`](../app/) ที่ `http://127.0.0.1:4317`

เปิด `chrome://extensions` → Developer mode → Load unpacked แล้วเลือกโฟลเดอร์นี้ ซึ่งมี `manifest.json` อยู่โดยตรง

ส่วนขยายอ่านข้อมูลสินค้าที่หน้า TikTok ตอบกลับ และใช้ขั้นตอนตรวจลิงก์สินค้าใน TikTok Creator เพื่อยืนยันค่าคอม ไม่กดเพิ่มสินค้าเข้าบัญชี ไม่รับเงื่อนไขแคมเปญ และไม่ส่ง Cookie หรือ Token บัญชีให้โปรแกรม

เมื่อแก้ไฟล์ส่วนขยาย ให้กด Reload ในหน้า Extensions และรีเฟรชหน้าโปรแกรมหลัก ดูรายละเอียดใน [คู่มือหลัก](../README.md)
